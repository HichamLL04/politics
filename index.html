📁 Estructura Limpia y Despliegue en GitHub Pages

Cada aplicación cuenta con su propia carpeta aislada dentro de apps/, lo que mantiene el repositorio impecable y genera URLs directas y elegantes para Google Play Console:

  1. URL pública de Tic Tac Toe: https://<tu-usuario>.github.io/politics/apps/tic-tac-toe/
  2. Añadir una nueva app: Simplemente crea apps/mi-otra-app/index.html (puedes copiar la plantilla de Tic Tac Toe) y añade su tarjeta en este portal.
  3. Activar en GitHub Pages: En tu repo de GitHub → Settings → Pages → Branch main y carpeta / (root) → Save.
